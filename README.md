# CR Auto Peças - Sistema de Gestão de Estoque e Vendas

> **Status do Projeto:** 🟡 Em desenvolvimento

## 🎯 Objetivo do Software
O **CR Auto Peças** é um sistema desktop desenvolvido para automatizar e otimizar o gerenciamento de estoque, compras, fornecedores e vendas de uma loja de auto peças, proporcionando controle financeiro e métricas visuais em tempo real para tomada de decisão.

## 🛠️ Tecnologias Aplicadas
- **Linguagem:** Java (JDK 17/21)
- **Interface Gráfica:** Java Swing (NetBeans GUI Builder)
- **Banco de Dados:** MySQL
- **Driver de Conexão:** JDBC (Java Database Connectivity)
- **Biblioteca de Gráficos:** JFreeChart
- **Versionamento:** Git & GitHub

## ⚙️ Funcionalidades do Sistema (Requisitos)
- [x] **Autenticação:** Tela de Login para acesso seguro ao sistema.
- [x] **Dashboard Principal:** Visualização de indicadores gerais (Total de SKUs, Alerta de Estoque Baixo, Vendas do Mês e Gráfico de Desempenho Semanal).
- [x] **Gestão de Estoque (CRUD):**
  - Cadastro de novas peças com SKU, valores e estoque mínimo.
  - Listagem e busca dinâmica por nome ou SKU.
  - Edição de informações de peças existentes.
  - Remoção de itens do banco de dados.
- [x] **Módulo de Fornecedores:** Cadastro e gerenciamento de fornecedores parceiros.
- [x] **Módulo de Compras:** Registro de entradas de peças no estoque.
- [x] **Módulo de Vendas:** Registro de vendas com atualização automática de métricas.
